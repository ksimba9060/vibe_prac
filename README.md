# 그린플레이트 프론트엔드

첨부된 모바일 디자인을 기반으로 만든 건강 맞춤 맛집 프론트엔드입니다.

## 실행

Node.js 18 이상에서 `npm run dev`를 실행하고 http://127.0.0.1:3000 에 접속합니다. 별도 패키지 설치는 필요하지 않습니다.

## 화면

홈, 추천 리스트, 검색, 건강 프로필, 건강 정보 설정, 매장 상세, 사진 갤러리, 지도, 리뷰 작성, 작성 리뷰 목록, 저장 식당 목록을 해시 경로로 제공합니다.

건강 필터, 저장 식당, 리뷰는 브라우저 localStorage에 유지됩니다. 검색, 카테고리 필터, 추천 정렬, 별점, 사진 첨부 미리보기, 리뷰 등록을 지원합니다.

## 검증

- `npm run check`: JavaScript 구문 검사
- `node smoke.cjs`: 전체 화면 렌더링 스모크 검사

## 데이터 범위

지도는 첨부 디자인에서 추출한 정적 이미지입니다. 매장 정보, 인증, 점수 및 영양 정보는 예시 데이터입니다. 서버 API, 실시간 지도, 로그인, 공공 데이터 연동 및 푸시 발송은 연결하지 않았습니다. 첨부 리뷰 사진은 세션 내 미리보기만 지원하며 저장되지 않습니다.

폰트는 Google Fonts를 사용하며 연결이 없으면 시스템 sans-serif로 표시됩니다. 음식 및 인테리어 이미지도 사용자 제공 시안에서 추출했습니다.
